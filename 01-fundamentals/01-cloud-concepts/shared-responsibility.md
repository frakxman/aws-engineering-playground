Question

What is the AWS Shared Responsibility Model?

Short answer

AWS secures the cloud.
Customers secure everything inside the cloud.

Interview explanation

AWS is responsible for protecting the physical infrastructure, networking hardware and managed services.

Customers are responsible for identity management, operating systems, applications, encryption, backups and access policies depending on the service model.

Example

EC2

AWS:
- Physical server
- Hypervisor
- Network

Customer:
- Linux
- Updates
- Firewall
- Application
- IAM Roles
