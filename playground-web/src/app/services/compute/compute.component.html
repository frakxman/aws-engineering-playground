AWS COMPUTE

Compute, explored.

Understand the AWS services used to run applications and workloads, from virtual machines to containers and serverless compute.

Compute ready
01 VIRTUAL MACHINES

Amazon EC2

Run workloads on virtual machines with control over compute capacity, networking, storage, and operating systems.

02 SERVERLESS

AWS Lambda

Execute code without managing servers and scale automatically based on incoming events and workload demand.

03 CONTAINERS

Amazon ECS

Run and orchestrate containerized applications using a managed container platform integrated with AWS infrastructure.

04 KUBERNETES

Amazon EKS

Operate Kubernetes workloads on AWS while using managed control-plane capabilities and the broader AWS ecosystem.

05 SERVERLESS CONTAINERS

AWS Fargate

Run containers without provisioning or managing the underlying servers, while integrating with ECS or EKS.

Choose the right compute model

CONTROL EC2 Maximum infrastructure control and flexibility.
SIMPLICITY Lambda Focus on application code without managing servers.
CONTAINERS ECS / EKS Choose based on orchestration requirements and platform needs.
