INSTANCE TYPES

Choose compute for the workload.

EC2 instance types define the balance of CPU, memory, networking, and other resources available to an instance. The right choice depends on what the workload actually needs.

GENERAL PURPOSE

T3

A balanced option for workloads with moderate and variable CPU usage, such as web applications and development environments.

COMPUTE OPTIMIZED

C5

Designed for compute-intensive workloads that benefit from higher CPU performance relative to memory.

MEMORY OPTIMIZED

R5

Provides more memory for workloads such as large in-memory datasets, caching, and memory-intensive applications.

NAMING c5.4xlarge

c5 identifies the instance family and generation, while 4xlarge identifies the instance size.

INSTANCE STORAGE

Persistent or temporary?

EC2 instances can use different storage options depending on whether application data needs to persist beyond the lifetime of the instance.

PERSISTENT BLOCK STORAGE

EBS

Amazon EBS provides persistent block storage that can remain available when an instance is stopped. It is commonly used for operating systems, applications, and data that must survive an instance restart.

USE WHEN Data must persist
TEMPORARY INSTANCE STORAGE

Instance Store

Instance Store provides high-speed temporary storage physically associated with the host. Data is lost when the instance is stopped or terminated.

USE WHEN Speed matters more than persistence
ENGINEERING DECISION

When does EC2 make sense?

CONTROL

When you need control over the operating system, instance configuration, networking, or installed software.

CONSISTENCY

When an application requires a long-running, dedicated compute environment.

FLEXIBILITY

When the workload does not fit naturally into serverless or container-based compute models.

INSTANCE LIFECYCLE

From launch to termination.

01

Pending

AWS is preparing the instance. The instance is being launched and configured before it becomes available.

02

Running

The instance is active and available for workloads. This is the primary state where compute charges accumulate.

03

Stopped

The instance is shut down but its EBS volumes can remain available for a later restart. Compute charges stop while it is stopped.

04

Terminated

The instance has been permanently deleted and cannot be restarted. Associated resources may have separate lifecycle rules.
