# Overview

The **AWS Engineering Playground** is my personal cloud engineering laboratory.

Its purpose is not to collect notes from AWS courses.

Instead, every folder contains practical implementations, architectural decisions, documentation, and reproducible labs that demonstrate real engineering knowledge.

This repository evolves continuously while preparing for:

- AWS Certified Cloud Practitioner
- AWS Certified Solutions Architect – Associate
- Cloud Engineering interviews
- Cloud-native software development

---

# Philosophy

This repository follows one simple rule:

> **Learn → Build → Document → Explain**

Every technology studied should produce a tangible artifact that demonstrates practical knowledge.
